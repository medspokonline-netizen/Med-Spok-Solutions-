# Medspok Solutions Pvt Ltd Website

A lightweight, fully static website for **Medspok Solutions Pvt Ltd**, Chennai, showcasing medical equipment available for **rent and sale**.

## Files

- `index.html` – Home
- `products.html` – Products
- `rent-or-buy.html` – Rent or Buy Guide
- `services.html` – Services
- `about.html` – About Us
- `contact.html` – Contact
- `medspok-catalogue-2026.pdf` – Product Catalogue

> Keep all files in the same folder.

## Features

- 100% Static HTML (No framework)
- Responsive design
- WhatsApp & Email enquiry
- Product catalogue
- Local SEO (Structured Data)
- Works offline

## Deployment

### Vercel

```bash
npx vercel login
npx vercel deploy --prod
```

When prompted:
- Directory: **Press Enter**
- Modify settings: **N**

### Netlify

Drag and drop the project folder at:

https://app.netlify.com/drop

## Troubleshooting

**404 Error?**

- Ensure `index.html` is in the project root.
- Remove any `vercel.json`.
- Leave all Vercel build settings empty.

## Before Publishing

- Verify manufacturer permissions for logos and images.
- Use your official company name consistently.
- Update the domain, canonical URL, and Open Graph tags if using a custom domain.
